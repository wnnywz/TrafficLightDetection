Проект представляет собой десктопное приложение на C# (Windows Forms) для анализа изображений. В программе реализованы базовые алгоритмы компьютерного зрения: цветокоррекция, бинарная маскировка и автоматическое обнаружение сигналов светофора с оценкой дистанции.

**Стек технологий:**
- **Язык:** C#.
- **Платформа:** .NET Framework / Windows Forms.
- **Работа с графикой:** System.Drawing (класс Bitmap, попиксельные операции, Graphics)

**Основные возможности:**

- **Попиксельный анализ:** Считывание точных RGB-значений любого пикселя по клику мыши.
- **Цветокоррекция (баланс белого):** Реализация метода «серого мира» с расчетом коэффициентов на основе выделенной пользователем области.
- **Цветовая фильтрация:** Настройка порогов (Min/Max RGB) для выделения нужного цвета и создания бинарной маски.
- **Поиск объектов по сетке:** Детектирование связных областей на маске с учетом заданного порога плотности заполнения и минимального размера.
- **Распознавание светофоров:** Автоматический поиск, выделение в рамку и классификация активных сигналов светофора (Красный, Желтый, Зеленый).
- **Оценка дистанции:** Приблизительный расчет расстояния до светофора (близко, средне, далеко) на основе габаритов обнаруженного объекта.

**Как запустить проект:**
1. Склонируйте репозиторий на свой компьютер:
```
   git clone https://github.com/wnnywz/TrafficLightDetection.git
```
2. Откройте файл решения tz2.slnx (или файл проекта .csproj) в Visual Studio.
3. Убедитесь, что установлены необходимые рабочие нагрузки для разработки классических приложений .NET (Windows Forms).
4. Нажмите кнопку Запуск (F5) на верхней панели среды разработки.
5. Программа скомпилируется и запустится автоматически. В поле «Рабочая папка» укажите путь к вашим тестовым изображениям.
